- Signal column: Replaced Signalling Description
- Label column : label

PIPELINE OVERVIEW
- train.csv is used ONLY for benign-only training.
- Each unique benign training dialog is treated as one softmax class.
- Therefore, model training is a benign-only multi-class classification task.

EVALUATION IS SPLIT INTO TWO TASKS
1) Known-benign classification (diagnostic only)
   - Evaluated only on benign test dialogs whose exact benign class was seen in training.
   - This is NOT anomaly detection.

2) Binary anomaly detection (main task)
   - Evaluated on the full test.csv.
   - Binary ground truth is assumed to be:
       0 = benign
       1 = anomalous
   - The model is still trained only on benign dialogs.
   - Anomaly detection is obtained by thresholding the softmax output.
