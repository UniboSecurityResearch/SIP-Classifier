LSTM PAPER-STYLE PIPELINE

TensorFlow version: 2.17.0
Seed: 42
GPU: allowed

This script reproduces the 4 LSTM architectures from the paper:
- Model 1.0 = LSTM(N) -> Dense(N)
- Model 1.1 = LSTM(N) -> Dropout(0.5) -> Dense(N)
- Model 2.0 = LSTM(N, return_sequences=True) -> LSTM(N) -> Dense(N)
- Model 2.1 = LSTM(N, return_sequences=True) -> LSTM(N) -> Dropout(0.5) -> Dense(N)

Unknown / anomalous dialog detection uses ONLY the paper LSTM detector:
- skewness / kurtosis threshold-based classifier
